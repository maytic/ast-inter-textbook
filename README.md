# Astronomy 2e — Interactive Study Guide

A static, hash-routed study guide for OpenStax *Astronomy 2e* (Chapters 1–2):
section reading with key ideas and self-checks, flashcards, a self-test quiz,
a glossary, per-chapter progress, and interactive tools and diagrams.

Plain HTML/CSS/JS — no build step. Open `index.html`, or serve the folder with
any static host.

Content adapted from [OpenStax Astronomy 2e](https://openstax.org/books/astronomy-2e),
licensed CC BY 4.0.
